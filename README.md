# SmartCity Connect – SDG 11 Prototype

## SDG Goal
SDG 11 – Sustainable Cities and Communities

## Problem Statement
Urban cities face challenges such as inefficient waste management,
delayed issue resolution, unsafe public spaces, and lack of citizen
participation in reporting city problems.

## System Objective
SmartCity Connect is a digital platform that enables citizens to
report urban issues and allows municipal authorities to monitor
and manage complaints efficiently, supporting sustainable city development.

## System Pages (Multi-Page Prototype)

### 1. Intro / Landing Page
- Explains SDG 11 and system purpose
- Entry point for users
- Navigation to citizen and admin modules

### 2. Citizen Complaint Page
- Citizens can report city issues
- Issue type and description captured
- Complaint ID generated
- Complaint status displayed

### 3. Municipal Dashboard (Admin View)
- Simulated view for municipal officers
- Displays submitted complaints
- Demonstrates stakeholder interaction
